# 自律神経系薬物シミュレーター

## 概要
自律神経系作用薬の投与に対する生体反応を、時間変化グラフで学習できるブラウザベースの教育用シミュレーターです。平均血圧（MAP）、心拍数（HR）、呼吸数（RR）の推移を同一画面で確認できます。

> **注意**  
> このアプリは**教育・学習目的のみ**を想定した簡略モデルです。**臨床判断、診断、治療方針の決定には使用しないでください。**

## デモURL
- GitHub Pages: https://vermilionheart.github.io/autonomic_nervous_system_drug_simulator/
- Repository: https://github.com/vermilionheart/autonomic_nervous_system_drug_simulator

## 機能
- MAP・HR・RR のリアルタイム表示
- 薬物投与後の時間変化を3段グラフで可視化
- 倍率変更、ズーム、パン、表示範囲調整
- 状態表示（正常 / 薬物作用中 / 回復中）
- Excel 出力
- PDF 出力
- PNG 出力
- 投与履歴の表示

## 使い方
1. ブラウザで `index.html` を開く
2. ベースライン値を設定する
3. 薬物と用量を選択する
4. シミュレーションを開始する
5. グラフ上で経時変化を確認する
6. 必要に応じて Excel / PDF / PNG を出力する

## 収録薬剤 / シミュレーション範囲
収録薬剤は以下です。

- アドレナリン
- ノルアドレナリン
- コカイン
- アセチルコリン
- フィゾスチグミン
- アトロピン
- ニコチン
- ヘキサメトニウム
- フェントラミン
- イソプロテレノール
- プロプラノロール
- エフェドリン塩酸塩
- ヒスタミン

シミュレーション対象の指標:
- 平均血圧（MAP）
- 心拍数（HR）
- 呼吸数（RR）
